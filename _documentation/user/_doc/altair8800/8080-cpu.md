# Intel 8080 CPU emulator

Altair 8800 originally came with processor [Intel 8080][8080cpu]{:target="_blank"}. It is an 8-bit microprocessor, from
1974.
The initial clock frequency was 2 MHz. This processor was one of the first general-purpose and widespread processors,
used not only in calculators but also in first personal computers. One of the key roles why this CPU become so popular
is that Gary Kildall targeted his CP/M to this CPU; and CP/M was de facto a "standard" in personal computers those
days.

Main features of the emulator include:

* Threaded-dispatch combined with interpretation as emulation technique,
* Correct real timing of instructions,
* Ability to change the clock frequency while paused or stopped,
* Emulation of all instructions including interrupts,
* Disassembler implementation,
* Instruction recording through the shared debugger,
* Support of breakpoints,
* Communication through 256 I/O port addresses,
* Status window shows all registers, flags, and run-time frequency.

## Configuration file

These settings belong in the CPU’s `[CPU.settings]` section. Remove `settings = { }` from `[CPU]` before adding a separate settings table.

|---
|Name | Default value | Valid values | Description
|-|-|-|-
|`frequency_khz` | 2000 | > 0 | CPU frequency set on emuStudio startup (it can be changed in runtime, but won't be saved in settings)
|---

## Recording executed instructions

Use **History** in the shared debugger to record recent instructions or continuously save execution to a file.
The recording includes sequence numbers, captured opcode bytes and disassembly, before/after register values,
raw flags, memory accesses and completion status. It works with both stepping and continuous execution.
See [Instruction recording]({{ site.baseurl }}/application/debugger-analysis#instruction-recording) for recording,
filtering, saving and opening recordings.

For unattended runs, use [automation recording]({{ site.baseurl }}/application/automation#instruction-recording):

```sh
./emuStudio -cf config/MITSAltair8800.toml auto --no-gui --waitmax 5000 --record-instructions 8080.emutrace
```
